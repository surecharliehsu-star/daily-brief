# 飞书交互机器人接入说明（每日信息专用应用）

> 每日信息使用**独立**飞书应用，与「自动化答复机器人」分开，互不干扰。

## 一、开放平台创建应用

1. 打开 [飞书开放平台](https://open.feishu.cn/app) → 创建企业自建应用
2. 应用名称建议：`每日信息bot`（测试）；凭证（App ID / App Secret）在「凭证与基础信息」页

## 二、权限配置（必须项）

| 权限 | 用途 | 开通位置 |
|------|------|----------|
| `im:message`（读取+发送） | 收取群消息指令、回复文本 | 权限管理 |
| `im:file`（上传文件） | 推送翻译 Word/PDF 文件消息 | 权限管理 |
| 使用长连接接收消息 | WebSocket 长连接事件订阅 | 事件订阅 → 长连接模式 |
| 机器人能力 | 出现在群内 | 应用能力 → 机器人 |

事件订阅**必须选择「使用长连接模式」**（否则需公网回调地址）。
添加事件：`im.message.receive_v1`（接收消息）。

## 三、测试环境配置

把以下信息填入 `每日信息-test/config.json`：

```json
"bot": {
  "app_id": "<应用App ID>",
  "app_secret": "<应用App Secret>",
  "allowed_approvers": ["<允许使用指令的用户open_id>"]
}
```

允许名单说明：
- 留空数组 `[]` = 默认全部允许（调试期可用 `*`）
- 填入 open_id = 仅这些用户可触发 `翻译` 等指令
- open_id 获取：飞书开放平台 → 调试工具 → 用应用发条消息查看事件 `sender_id.open_id`，或让用户与机器人私聊后在日志中查看

## 四、启动

```bash
python3 -m src.daily_papers.bot.run --check   # 自检依赖
python3 -m src.daily_papers.bot.run           # 长连接常驻，等待群消息
```

## 五、群内指令

| 指令 | 说明 |
|------|------|
| `列表` | 今日简报论文列表（编号） |
| `摘要 <编号>` | 查看该论文中文摘要 |
| `翻译 <编号>` | 全文翻译，完成后向本群推送 Word + PDF 文件 |
| `帮助` | 显示指令说明 |

## 六、生产部署（测试通过后）

1. 正式 `每日信息/config.json` 配置正式群应用凭证 + 白名单
2. launchd 守护进程运行 `bot/run.py`（常驻）
3. 按 `docs/升级SOP.md` merge dev → master
